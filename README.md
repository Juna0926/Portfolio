# Junha Won — Research Portfolio

Undergraduate researcher in **Industrial Engineering at Ajou University**, working on **Digital Healthcare, longitudinal/time-series health data, patient-generated data, and medical image AI**.

My current research uses the **BRIGHTEN** dataset to study whether individualized behavioral anomalies in passive smartphone sensing precede subsequent changes in depression severity. Previous work includes label-efficient lesion localization and robustness analysis for patient-captured stoma images, as well as LSTM-based digital-phenotype mental-health prediction.

**Live site:** https://juna0926.github.io/Portfolio/

## Research focus
- Longitudinal and within-person health modeling
- Passive smartphone sensing and digital phenotyping
- Personalized mental-health monitoring
- Annotation-efficient medical image localization
- Robustness and interpretability in medical AI

## Site structure
- `index.html` — research-first overview
