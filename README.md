## Current Research
**Longitudinal Behavioral Anomaly Detection for Depression Monitoring Using Passive Smartphone Sensing Data**

BRIGHTEN V1 passive smartphone sensing and repeated PHQ-9 assessments are aligned into participant-level longitudinal data. The study develops a passive-sensing-only machine-learning model for PHQ-9-based depression-severity prediction, detects individualized behavioral anomalies, and evaluates whether these deviations precede subsequent PHQ-9 changes through lagged temporal analysis. A sole-author manuscript is in preparation.
