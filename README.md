# Junha Won — Research Portfolio

Undergraduate researcher in **Industrial Engineering at Ajou University**, working on **Digital Healthcare, Medical AI, longitudinal & time-series health data, and medical image analysis**.

My current research uses **BRIGHTEN V1** to construct participant-level longitudinal datasets from passive smartphone sensing and repeated PHQ-9 assessments, predict PHQ-9–based depression severity using passive sensing data, and evaluate whether individualized behavioral anomalies precede subsequent PHQ-9 changes using lagged temporal analysis. Previous work includes data-efficient stoma lesion localization with WSOL and domain-informed pseudo-label refinement, deep-learning-based stoma image classification with Grad-CAM-driven shortcut analysis, and LSTM-based digital-phenotype mental-health prediction.
