HEALTHCARE INFORMATION SYSTEM

AI-Based Hospital Information System for Clinical and Insurance Prediction

Sep. 2025 — Dec. 2025MySQL · Random Forest · Flask

Normalized MySQL hospital database에 clinical and insurance prediction models와 Flask-based web interface를 연결해 data → prediction → database update → browser output으로 이어지는 healthcare information-system prototype을 구축했습니다.

12Normalized entities
MySQLRelational database
FlaskWeb interface

Database

Patient, clinician, encounter, diagnosis, medication, insurance, and prediction workflows를 포함하는 normalized relational schema를 MySQL로 구현했습니다.

Prediction

Random Forest-based clinical and insurance prediction modules를 구축하고 prediction result와 model metadata를 database workflow에 연결했습니다.

Service layer

Flask-based web interface를 통해 사용자 입력, prediction 실행, DB update, browser-based result display가 하나의 흐름으로 동작하도록 통합했습니다.

End-to-end integration

Database design과 machine-learning model을 분리된 산출물이 아니라 하나의 healthcare decision-support prototype으로 연결한 점이 핵심입니다.

Project takeaway

Healthcare AI model은 알고리즘 자체뿐 아니라 data structure와 operational workflow 안에서 어떻게 연결되는지가 실제 시스템 구현에 중요하다는 점을 경험했습니다.
