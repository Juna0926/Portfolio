HEALTHCARE & POPULATION DATA ANALYSIS

Depression Risk Profiling with KNHANES & Air-Pollution Data

2025 Healthcare Big-Data ProjectK-Means · SMOTE · Random Forest

국민건강영양조사의 건강·생활·사회경제·영양 정보와 연계 대기오염 변수를 통합하고, 전체 인구를 하나의 집단으로 가정하기보다 서로 다른 특성을 가진 하위집단별 우울 위험 구조를 분석한 프로젝트입니다.

14,773Observations
71Variables
K=5Participant profiles

Data

2014, 2016, 2020, 2022년 KNHANES의 검진·건강설문·영양 자료와 환경 노출 변수를 결합하고, 결측 및 유효성 처리와 범주형 one-hot encoding, 연속형 scaling을 거쳐 분석 데이터를 구성했습니다.

Analytical strategy

  • K-Means로 5개 participant profile 구성
  • 군집 내부 class imbalance에 SMOTE 적용
  • 분류 모델 비교
  • 군집별 Random Forest feature importance 해석

Key insight

우울 위험과 연결되는 주요 변수는 모든 사람에게 동일하지 않았습니다. 연령·생활양식·사회적 지지·만성질환·영양 및 환경 노출의 상대적 중요성이 군집별로 달라, subgroup-specific risk profiling의 필요성을 보여주었습니다.

Interpretation

이 결과는 관찰자료에 기반한 위험 구조 탐색이며 인과효과를 의미하지 않습니다. 군집 또한 임상적 진단군이 아니라 분석을 위한 population profile입니다.

Project significance

국가 건강조사와 환경 데이터를 함께 보면서 population heterogeneity를 분석에 명시적으로 반영했다는 점이 핵심입니다. 하나의 평균적 위험모델 대신, 서로 다른 하위집단에서 어떤 요인이 상대적으로 중요해지는지를 비교하는 방향으로 분석을 확장했습니다.
