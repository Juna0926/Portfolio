HEALTHCARE DATA ANALYSIS

Depression Risk Prediction Using KNHANES Data

Jun. 2025 — Sep. 2025K-Means · SMOTE · Random Forest

KNHANES와 air-pollution data를 결합해 heterogeneous population의 subgroup-specific depression-risk profile을 분석하고 machine-learning prediction으로 연결한 프로젝트입니다.

14,773Observations
71Variables
0.7378Average AUC

Data

KNHANES health, lifestyle, socioeconomic, nutrition variables와 linked air-pollution variables를 통합했습니다.

Subgroup profiling

K-Means로 population subgroups를 구성하고 각 subgroup 내부의 class imbalance에 SMOTE를 적용했습니다.

Prediction

Machine-learning classifiers를 비교하고 Random Forest를 중심으로 subgroup-specific depression-risk pattern을 평가했습니다.

Result

최종 분석에서 Random Forest가 average AUC 0.7378을 기록했습니다.
